# F1 Dashboard

**Live:** [fvibe1.netlify.app](https://fvibe1.netlify.app/)

---

## Description

A dashboard for Formula 1 enthusiasts displaying race results, driver standings, and constructor information. Features national anthem playback for drivers and constructors. Integrates various F1-related APIs.
