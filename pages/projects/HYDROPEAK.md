# HydroPeak Calendar

Hydro-Québec peak events as a subscribable calendar for residential customers.

---

## How to Use

Add this URL to your calendar software (Google Calendar, Apple Calendar, Outlook, etc.):

```
https://unofficial-hydroqc-peak-calendar.b-cdn.net/
```

Copy and paste the URL into your calendar's "Add calendar from URL" feature. The calendar will automatically update with upcoming peak events.
