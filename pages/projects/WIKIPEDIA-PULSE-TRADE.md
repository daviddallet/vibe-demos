# Wikipedia Pulse Trade

**Live:** [wikipulsetrade.netlify.app](https://wikipulsetrade.netlify.app/)

**Note:** Desktop only, not suitable for mobile screens or metered connections.

---

## Description

A real-time visualization and trading game based on Wikipedia edits. Watch edits stream in live, then trade them like stocks — each edit type becomes a tradeable ticker. Buy low, sell high, and compete against the flow of human knowledge.

---

## Technical

Built with the Wikimedia EventStreams API for real-time data.
