# PDF Tools

**Live:** [pdf.pwasuite.com](https://pdf.pwasuite.com/) | **Repository:** [pwasuite/pdftools](https://github.com/pwasuite/pdftools)

---

## Overview

Browser-based PDF manipulation tools: compress, merge, split, extract pages, convert to grayscale, change page format. Uses Ghostscript compiled to WebAssembly.

**Key feature:** Files are never uploaded to a server — everything runs locally in the browser, providing privacy by design.

---

## Origin

Forked from an open-source Ghostscript WASM project that only had PDF compression. Used AI-assisted development to rebuild the UI and add multiple new features.

---

## Progressive Web App

Installable as a Progressive Web App for offline use.
