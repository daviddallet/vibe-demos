# Pointes HQ Peaks

**Live:** [pointes-hq-peaks.b-cdn.net](https://pointes-hq-peaks.b-cdn.net/)

---

## Overview

Installable Progressive Web App for browsing Hydro-Québec peak demand events.
Shows upcoming and past events in a card-based interface with date, time window,
and event type. Features residential plan-type filtering (Flex D, Crédit hivernal),
bilingual FR/EN toggle, real-time data refresh, and full offline support.

## Technical

Built with Lit (Web Components) and Vite. Uses a custom service worker for
offline caching and CDN-delivered data from Hydro-Québec Open Data.

---

## Data Source

Peak event data from [Hydro-Québec Open Data](https://donnees.hydroquebec.com/explore/dataset/evenements-pointe/information/), licensed under Creative Commons CC-BY-NC 4.0.
