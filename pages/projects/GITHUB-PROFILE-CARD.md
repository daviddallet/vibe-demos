# GitHub Profile Card Generator

**Live:** [ghprofilecard.netlify.app](https://ghprofilecard.netlify.app/)

---

## Description

A profile card generator that fetches GitHub user data and displays it in a shareable format.

---

## Features

- User stats: repositories, followers, stars
- Top repositories with star counts
- Language breakdown chart
- Four color themes: Dark, Light, Ocean, Forest
- Animated stat counters
- PNG export functionality

---

## Technical

Uses GitHub REST API with caching and CORS proxy fallbacks.
