# Identity Detective

**Live:** [namedetective.surge.sh](https://namedetective.surge.sh/)

---

## Description

A detective-themed name profiler that queries 4 public APIs in parallel:

- **Agify** — age prediction
- **Genderize** — gender prediction
- **Nationalize** — nationality prediction
- **REST Countries** — country details

Displays predictions with animated confidence bars. Click "EXPLORE CASE FILE" to reveal technical details: endpoints, status codes, response times, and raw JSON responses.

---

## Design

Dark glassmorphism UI with a "CLASSIFIED" aesthetic.

---

## Note

For demonstration purposes only — predictions should not be taken seriously.
